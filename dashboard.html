hub

End-to-End System Architecture

Sensor to cloud to dashboard data flow.

Stage 01

Environmental Sensors

DHT22 measures temperature and humidity. MQ-2 provides an analog gas sensor reading.

DHT22 → GPIO 15
MQ-2 → GPIO 34
Stage 02

ESP32

Reads sensors, checks thresholds and prepares the telemetry request.

Wokwi Simulation
Stage 03

Wi-Fi

ESP32 connects to Wi-Fi and sends sensor data to the cloud.

HTTP / HTTPS
Stage 04

ThingSpeak

Stores temperature, humidity, gas and alert values as time-series data.

Channel #3524286
Stage 05

Custom Dashboard

Fetches the latest ThingSpeak values and displays sensor status and alerts.

HTML + JavaScript
info
Hardware Specification Note

The original problem statement specifies DHT11. This prototype uses DHT22 in Wokwi because it is the sensor available in the simulation. The MQ-2 value shown here is an ADC reading from 0-4095, not a calibrated PPM concentration.

security

Security Considerations

Open Ports

IoT devices exposed to unnecessary network ports can become attack targets.

Default Credentials

Default usernames and passwords should be replaced with strong credentials.

Unencrypted Data

HTTPS/TLS should be used when transmitting IoT data over the internet.
